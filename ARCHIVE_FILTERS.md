# Техническое задание. Фильтры архива DocStation

На странице архива добавить поиск по названию, диапазон дат, выбор формата исходника и выбор операции. Даты можно указать по отдельности. Границы включаются и вычисляются в часовом поясе приложения.

- Без выбранной операции период применяется к дате последнего обновления документа.
- При выборе операции период применяется к дате создания успешно завершённой задачи. Формат должен совпадать с форматом версии, которая участвовала в этой задаче.
- Фильтр формата ищет по всем версиям документа. JPEG и JPG, а также TIFF и TIF считаются одним форматом.
- Критерии действуют совместно. Показываются только документы текущего пользователя, каждый один раз. Группировка по дням последнего обновления и сортировка от новых к старым сохраняются.
- Критерии передаются в URL и сохраняются при листании. «Сбросить» возвращает полный архив. При ошибке в параметрах форма показывает сообщение.

Приёмка. При выборе PDF, операции «Сжать PDF» и периода прошлого месяца отображаются документы с успешной задачей сжатия исходного PDF, созданной в указанный период. Неуспешные задачи, задачи за пределами периода и документы другого аккаунта исключаются.
